# 🎬 CINEXA – Movie Review Website

**CINEXA** is a movie discovery and review website designed for movie enthusiasts. It allows users to explore movies, discover trending titles, view movie information, and stay updated with the world of cinema.

Built with a modern interface and powered by the **OMDb API**, CINEXA brings movie information together in one place.

## ✨ Features

- 🎥 **Movie Discovery** – Explore a wide range of movies.
- 🔍 **Search Movies** – Search for movies by title.
- ⭐ **Movie Ratings** – View movie ratings and reviews.
- 📖 **Movie Details** – Access information such as plot, cast, genre, director, and release year.
- 🖼️ **Movie Posters** – Browse movies with their official posters.
- 🌐 **API Integration** – Fetch movie information dynamically using the OMDb API.
- 📱 **Responsive Design** – Enjoy the website across different screen sizes.

## 🛠️ Technologies Used

- HTML5
- CSS3

- OMDb API

## 🚀 Getting Started

Follow these steps to run CINEXA locally.

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/cinexa.git
```

### 2. Navigate to the Project Folder

```bash
cd cinexa
```

### 3. Configure the API Key

1. Visit [OMDb API](https://www.omdbapi.com/apikey.aspx).
2. Generate your API key.
3. Add your API key to the JavaScript configuration.

```javascript
const API_KEY = "YOUR_OMDB_API_KEY";
```

### 4. Run the Website

Open `index.html` in your browser or use the VS Code Live Server extension.

## 🔑 API Reference

CINEXA uses the [OMDb API](https://www.omdbapi.com/) to retrieve movie information.

Example API request:

```text
https://www.omdbapi.com/?t=Inception&apikey=YOUR_API_KEY
```
